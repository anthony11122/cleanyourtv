# 海信 VIDAA_TV（本次实测机）清理清单 —— 29 个包
#
# 机型：VIDAA_TV（国内 JuUI / 聚好看固件，电视设置里型号就叫这个）
# 芯片：MT9653，板号 mt5879
# 系统：Android 11（SDK 30）
# 固件：RP1A.200720.011 / 02.02.70.01，安全补丁 2022-09-05
# 内存/存储：3.8 GB RAM，41 GB 可用，UI 1080p / 320 dpi
#
# 用法：
#   TV_HOST=<电视 IP> tools/disable.sh examples/hisense-vidaa-mt9653-cn/debloat.txt
# 恢复：
#   TV_HOST=<电视 IP> tools/restore.sh examples/hisense-vidaa-mt9653-cn/debloat.txt
#
# 全部是 pm disable-user，不是卸载。包还在系统里，pm enable 就能回来。
# 用不上的行注释掉再跑，别整份照抄。
#
# ⚠ 三条硬性警告，先看完再动手：
#
# 1) com.hisense.tv.tiletransition 不能禁。
#    名字看着像「转场动画」，实际它承载 TileAnimationService：厂商输入源面板在切换输入前必须先绑这个
#    服务。禁掉之后面板照样能打开、照样有动画，但选 HDMI 什么都不会发生，logcat 里是
#       Unable to start service Intent { act=com.hisense.tv.tiletransition.TileAnimationService } not found
#    所以它不在下面这 29 个包里。
#
# 2) com.jamdeo.tv.vod 是原桌面，只在新桌面已经起来并设为 HOME 之后才能禁。
#    它是这台机器上唯一带开机广播（BOOT_COMPLETED）的桌面：先禁它、再装新桌面，中间那次重启就是黑屏。
#    正确顺序：装新桌面 → 确认 Home 已经是新桌面 → 再跑这份清单。
#    tools/disable.sh 也会拦一道：如果清单里有 Home 的持有者、而电视上没有别的应用应答 HOME，
#    它会跳过这一条并说明原因。别用 FORCE_HOME=1 绕过它。
#
# 3) 下面 29 个包同时包含 OTA 三件套：com.jamdeo.updateservice、com.hisense.usbupgrade、
#    com.hisense.playerupdate。禁掉它们 = 永久停止固件更新，不再有安全补丁；海信只能靠官方 OTA 或
#    售后刷机恢复，自己刷不回来。要更新就先 pm enable 这三个包，更新完再禁。
#    不想停更就把这三行注释掉。
#
# 顺带说明：这份清单不会改变原桌面的样子。聚好看的运营位和 VIP 横幅是 com.jamdeo.tv.vod 自己拉的，
# 禁旁路广告包动不了它们，只有换桌面才行。这份清单买到的是：遥测、推送、常驻轮询进程和一堆广告进程。
